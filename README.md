# AI Chess Engine

An AI-powered chess game built using Python and Pygame. The project allows a player to play chess against a computer-controlled AI opponent that uses the Minimax algorithm and Alpha-Beta pruning to make decisions.

## How to Run

Install Pygame:

```bash
pip install pygame
```

Then run:
```bash
Chess_game.py
```
Make sure the images folder is in the same directory as the Python file.
